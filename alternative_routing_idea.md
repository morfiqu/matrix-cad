# Альтернативная идея волновой разметки узлов (Connected Component Labeling / Flood Fill)

Данный документ описывает идею упрощения алгоритмов коммутации и поиска КЗ (коротких замыканий) на схеме, предложенную пользователем.

## Основная суть идеи
Вместо ведения сложных путей (BFS от каждого пистолета к инверторам) мы можем красить всю замкнутую электрическую цепь в уникальный идентификатор (ID) источника (инвертора).

1. **Синхронность полюсов (+ и -)**:
   Так как все операции с коммутацией контакторов полюсов происходят синхронно (мы не можем подключить только плюс или только минус отдельно), мы можем логически представить пару проводов как одну линию.

2. **Распространение ID сети (Flood Fill)**:
   - У каждого инвертора есть свой постоянный ID сети (например, `idinv1` для `inv1`).
   - Каждая ячейка провода (клеточка сетки) получает ID сети источника, к которому она подключена.
   - Изначально (при разомкнутых контакторах) все сегменты, не подключенные к источникам, имеют ID = `0`.
   - ID `0` — это специальный статус «висящий провод». Несколько элементов с ID `0` не считаются соединенными между собой (это исключение).

3. **Работа с контакторами и разделителями**:
   - При замыкании разделителя/контактора ID сети распространяется дальше по цепи.
   - Пример:
     - `inv1` -> `провод (idinv1)` -> `[Разделитель]` -> `провод (id = 0)`
     - Замыкаем разделитель: провод справа получает `idinv1`.

4. **Работа с межплатными клеммами/кабелями**:
   - Если цепь утыкается в клемму `C1`, эта клемма регистрируется с текущим ID цепи (`idinv1`).
   - Все ответные клеммы с именем `C1` на других листах автоматически получают этот же ID (`idinv1`) и передают его дальше по подключенным к ним проводам.
   - Чтобы избежать бесконечного зацикливания при кольцевых схемах (`C1` -> `C1` и т.д.), алгоритм волны должен использовать список посещенных узлов (`visitedNodes`).

5. **Слияние нескольких источников (КЗ и параллельная работа)**:
   Если к одной цепи подключается второй инвертор `inv2` (у которого свой ID `idinv2`), возможны два варианта обработки:
   - **Вариант 1 (Композитные ID)**: Провод получает составной ID `idinv1, idinv2`. Этот ID распространяется по всей цепи. Позволяет точно знать все источники. При размыкании контактора цепи делятся обратно (требует пересчета).
   - **Вариант 2 (Наследование по приоритету)**: Устанавливается приоритет (например, меньший номер ID вытесняет больший). Линия наследует `idinv1`, пока физически подключена. При размыкании разделителя линия `inv2` сбрасывается в `0` и перекрашивается в `idinv2`.

---

## Преимущества
- **Простое обнаружение ошибок (КЗ)**: Если в одну ячейку (или пистолет) пытаются прийти два разных активных ID инвертора, мы сразу регистрируем ошибку короткого замыкания.
- **Быстрый расчет**: Алгоритм волны (Flood-Fill) пишется очень легко и быстро обходит сетку по замкнутым контакторам.
