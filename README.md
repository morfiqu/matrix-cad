# ⚙️ EV Switching Matrix CAD & Designer

Веб-приложение для проектирования, коммутации и физического моделирования многоточечных силовых матриц зарядных станций электромобилей.

## 🚀 Архитектура проекта

Приложение разделено на независимые ES6-модули:

```
S:\matrix_cad\
├── index.html           # Главный HTML-интерфейс
├── css/
│   └── style.css        # Дизайн-система и стили CAD-холста
└── js/
    ├── solver.js        # Математический движок симуляции (BFS, Кирхгоф, кольца)
    ├── cad_engine.js    # Отрисовка SVG-сетки, проводов, контакторов и автоматов
    ├── ui.js            # Состояние приложения, история (Undo/Redo), импорт/экспорт
    └── app.js           # Точка входа приложения
```

## ⚡ Особенности движка

- **Многостраничные схемы:** Связывание независимых листов через сквозные кабельные сети (`C1`, `C2`, `CL`...).
- **Точный расчет мощности:** Вычисление токов с учетом $N$-угольных колец Кирхгофа, параллельных ветвей и замкнутых состояний автоматов.
- **Поддержка Git:** Полный контроль версий репозитория.

## 🛠️ Запуск проекта

Открыть `index.html` в любом современном браузере. Внешние сборщики не требуются.
